================================================================================
  INSTALLATION STEPS (5 MINUTES)
================================================================================

STEP 1: Check Python
---------------------
Open Command Prompt/Terminal and type:
  python --version        (Windows)
  python3 --version       (Mac/Linux)

You need Python 3.8 or higher.
If not installed: Download from https://www.python.org/downloads/


STEP 2: Navigate to Project Folder
-----------------------------------
cd path\to\adaptive-network-emulator        (Windows)
cd path/to/adaptive-network-emulator        (Mac/Linux)


STEP 3: Create Virtual Environment
-----------------------------------
python -m venv venv                         (Windows)
python3 -m venv venv                        (Mac/Linux)


STEP 4: Activate Virtual Environment
-------------------------------------
venv\Scripts\activate                       (Windows CMD)
venv\Scripts\Activate.ps1                   (Windows PowerShell)
source venv/bin/activate                    (Mac/Linux)

You should see (venv) at the start of your prompt.


STEP 5: Install Dependencies
-----------------------------
pip install -r requirements.txt

This installs:
  - pytest (testing framework)
  - hypothesis (property-based testing)
  - Flask (web dashboard)
  - numpy (numerical operations)
  - pyyaml (configuration)
  - pyshark (packet analysis)

Installation takes 2-5 minutes.


STEP 6: Verify Installation
----------------------------
python -c "import flask, hypothesis, pytest; print('✓ Ready!')"

You should see: ✓ Ready!

================================================================================
  TROUBLESHOOTING
================================================================================

Problem: "Python is not recognized"
Solution: Install Python and add to PATH during installation

Problem: "pip is not recognized"  
Solution: python -m pip install --upgrade pip

Problem: "Permission denied" (Windows PowerShell)
Solution: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

Problem: Dashboard doesn't open
Solution: Check if port 5000 is free, try http://127.0.0.1:5000

Problem: "Module not found"
Solution: Make sure venv is activated, reinstall: pip install -r requirements.txt

Problem: Tests fail
Solution: Clear cache: rm -rf .hypothesis/ .pytest_cache/ __pycache__/
